Short Summary

Read This First

LuckyBot+ stores a limited set of Discord identifiers and virtual game data necessary to operate its economy, player profiles, casino-style games, lottery system, announcements, and server configuration features. No real personal information beyond what Discord already stores about you is collected. We do not sell, rent, share, or commercialize your data in any form. You can request deletion of your data at any time by contacting the bot owner.

// Data Collection
01

Information We Collect

Transparency

The bot may store the following information when you or your server use its features. All data collected is strictly limited to what is required for the bot to function correctly.

Data Type Examples Purpose Required
Discord User ID Numeric Discord user identifier To maintain balances, EXP, statistics, game states, and profiles per user. Yes
Discord Guild ID Numeric Discord server identifier To store server-specific announcement channel settings and server configuration. Yes
Channel & Message IDs Channel ID, Message ID To send, edit, recover, or replace game announcement embeds and result messages. Yes

Operational Logs Error messages, command failure timestamps, stack traces To debug issues, maintain bot security, and improve reliability over time. Temporary
02

Information We Do Not Collect

Boundaries

To be explicit about what we do not collect:

  • Passwords, authentication tokens, or account credentials of any kind.
  • Payment information, financial data, bank account numbers, or credit card details.
  • Government-issued identification, real names, physical addresses, or personally identifiable information (PII) beyond Discord's internal numeric IDs.
  • Email addresses — you are never required to provide an email to use this bot.
  • Message content, private messages, or the contents of any Discord channels (the bot only reads commands directed at it).
  • Device information, IP addresses, browser fingerprints, or geolocation data.
  • Real money, cryptocurrency, or any financial transaction data.
  • Information about users who never interact directly with the bot via commands.
// Data Usage & Storage
03

How We Use Information

Purpose

All collected data is used exclusively for operating the bot's features. Specifically, stored data is used to:

  • Create and maintain individual player profiles, virtual balances, experience points, and statistics.
  • Start, save, resume, and resolve casino-style game sessions for users across bot restarts.
  • Enforce one-active-game-per-user rules and prevent exploitation of the economy system.
  • Manage and distribute lottery tickets and process scheduled lottery draws.
  • Send, edit, and recover Discord embed messages and game result announcements in configured channels.
  • Maintain server-specific configuration such as designated announcement channels.
  • Respond to support and abuse inquiries, investigate reported bugs, and diagnose operational errors.
  • Detect and prevent abuse, exploitation, cheating, or violations of these Terms.

Data is never used for advertising, profiling, marketing, or any purpose unrelated to operating the bot.

04

Data Storage & Security

Infrastructure

Bot data is stored in a database controlled and maintained by the bot owner. The following technical measures are applied to protect stored data:

  • Access to the database is restricted to authorized bot processes and the bot owner only.
  • Database credentials and connection strings are stored securely and are never exposed publicly.
  • The server and database software are kept up to date to mitigate known security vulnerabilities.
  • Operational logs containing sensitive debug information are retained for a limited period and are not publicly accessible.

However, no system connected to the internet can guarantee absolute security. While we apply reasonable safeguards, we cannot warrant that stored data will be completely immune to unauthorized access, data breaches, or unforeseen security events. In the event of a significant data breach affecting user data, we will make reasonable efforts to notify affected users through available channels.

05

Data Sharing

Third Parties

We do not sell, rent, trade, lease, or otherwise transfer your data to third parties for any commercial purpose. Data may only be shared in the following limited and necessary circumstances:

  • Hosting providers: The database and bot process run on infrastructure provided by a hosting service. This provider may have incidental access to stored data as part of their infrastructure operation, governed by their own privacy policies.
  • Security or abuse response: If we believe your account is involved in a security incident, attack, or serious abuse of the bot, relevant data may be reviewed or shared as part of the investigation.
  • Legal compliance: We may disclose data if required by a valid legal process, court order, law enforcement request, or other binding legal obligation.
  • Discord platform: The bot operates on Discord's platform, and your use of Discord is additionally governed by Discord's own Privacy Policy and Terms of Service.

Beyond the above, no data will be shared with any third party without your explicit consent.

// Retention & Rights
06

Data Retention

Lifecycle

// Persistent Data

  • Player profiles, virtual economy balances, experience points, and lifetime statistics are retained while the bot continues to provide services and the user's data has not been requested for deletion.
  • Server configuration data (announcement channels, settings) is retained for as long as the bot remains active in the server.

// Temporary Data

  • Active game session data (card states, bets, choices) is deleted automatically after the game resolves or the session expires.
  • Lottery ticket records are cleared after each lottery draw cycle completes.
  • Operational logs and error traces are retained for a limited time (typically 30–90 days) for debugging and security review, then purged.

// Extended Retention

  • Some data may be retained beyond standard periods if necessary to investigate active abuse cases, resolve ongoing disputes, or comply with applicable legal obligations.
07

Your Rights & Data Control

User Rights

Depending on your jurisdiction, you may have certain rights regarding your personal data. We respect these rights and will honor valid requests to the best of our ability:

  • Right to access: You can request a summary of what data the bot holds associated with your Discord User ID.
  • Right to deletion: You can request that your bot-related data (profile, balance, game history) be deleted by contacting the bot owner. Note that some data may be temporarily retained if needed for active security investigations or ongoing game resolution.
  • Right to correction: If you believe data associated with your account is inaccurate, you may request a review.
  • Right to restriction: You may request that we stop processing your data in certain ways while a deletion or correction request is pending.

Server owners may additionally request removal of their server's configuration and guild-level data by contacting the bot owner and confirming their ownership of the relevant server.

To exercise any of these rights, please contact the bot owner using the contact information provided in Section 12. We aim to respond to all valid requests within 30 days.

08

Children's Privacy

Protection

LuckyBot+ is not directed at or designed for children who are not permitted to use Discord under Discord's Terms of Service for their region. We do not knowingly collect, store, or process personal information from users who do not meet Discord's minimum age requirement.

If a parent or guardian believes their child has interacted with the bot in violation of Discord's age requirements, they should contact the bot owner immediately. We will take reasonable steps to delete any data associated with the user's account upon confirmation.

Server administrators have a particular responsibility to ensure the bot is used appropriately within their community, including enforcing age-appropriate access.

09

Security Practices

Security

We take the security of stored data seriously and implement reasonable technical and organizational measures to protect it from unauthorized access, alteration, disclosure, or destruction. Specific measures include:

  • Database access is restricted exclusively to the bot process and the bot owner — no public database endpoints are exposed.
  • All credentials, tokens, and API keys are stored as environment variables and are never committed to any public code repository.
  • The bot host and database server software are regularly updated to apply security patches.
  • Sensitive operational logs are stored separately from economy data and have restricted access.

Despite these measures, no internet-connected system can provide absolute security guarantees. You use this bot understanding that residual security risks exist, as with any online service.

Third-Party Services

External

The bot depends on a number of third-party services and platforms as part of its infrastructure:

  • Discord: The bot operates entirely on Discord's platform. Discord collects its own data about users as described in Discord's Privacy Policy at discord.com/privacy. We have no control over Discord's data practices.
  • Hosting provider: The bot process and database are hosted on a third-party server or cloud infrastructure provider. This provider operates under its own privacy and data handling policies.
  • Database service: If a managed database service is used (e.g., a cloud database provider), that provider may have incidental access to stored data under the terms of their service agreement.

We encourage you to review Discord's own Privacy Policy as it governs the majority of data associated with your use of Discord and any bots operating on it.
