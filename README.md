# Discord Blackjack Bot

Python Discord bot mini game Blackjack, designed to be expanded with more games later.

## Setup

1. Create virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Copy `env.example` to `.env` and fill `DISCORD_TOKEN`.
4. Run bot:

```bash
python bot.py
```

## Commands

- `/bet <amount>`
- `!bet <amount>`
- `/profile`, `!profile`
- `/coins`, `!coins`

See `blackjack_bot_spec.md` for detailed specification.
